# Dataset documentation

`offers.csv` is generated by `src/generate_data.py` and contains **synthetic demonstration data**. It is not scraped from, affiliated with, or representative of any real retailer. Prices, discounts, shipping charges, coupon rules, stock status, and delivery windows are fictional and generated with a fixed random seed for reproducibility.

## Coverage
- 15 example products across Electronics, Home, Stationery, and Fashion
- 3 fictional shopping platforms: ShopKart, MegaMart, and QuickBuy
- One offer row per product/platform pair (45 rows)
- Currency: INR

## Key fields
| Field | Meaning |
|---|---|
| `product_id`, `product_name`, `category` | Product identifiers and descriptors |
| `platform` | Fictional marketplace name |
| `listed_price` | Before-discount unit price in INR |
| `discount_pct` | Percentage reduction from listed price |
| `shipping_fee` | Shipping cost before free-shipping rule |
| `free_shipping_min` | Order subtotal threshold for free shipping |
| `coupon_code`, `coupon_pct` | Illustrative coupon and percentage discount |
| `coupon_min_spend` | Minimum eligible subtotal for coupon |
| `coupon_max_discount` | Coupon discount cap in INR |
| `in_stock` | Whether the offer can be purchased |
| `delivery_days` | Synthetic delivery estimate in days |
| `data_type` | Always `synthetic_demo` for this generated file |

Regenerate it using `python src/generate_data.py`. Replace it with a properly licensed, documented real dataset only after mapping the same columns and checking the retailer terms of service. Never describe synthetic outputs as observed customer savings.
